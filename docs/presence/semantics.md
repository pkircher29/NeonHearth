# Presence semantics

The presence engine is deterministic: callers supply both observation and arrival/evaluation timestamps, and evaluation time may never move backwards. Evidence is accepted only from the engine-configured trusted-source registry; ordinary evidence cannot claim verified enforcement, which has a separate API. Inputs, devices, evidence, history, and per-operation work are bounded.

`Blocked` has highest precedence and requires verified enforcement; it remains until verified unblock. `Unknown` follows for sensor impairment or contradiction and never fabricates departure. `Online` requires recent trusted traffic. `Quiet` requires prior real presence plus a still-valid lease, router association, or successful probe; a probe alone cannot establish presence. `Offline` requires prior real presence, expiration of all protocol support, and the configured number of confirmation failures strictly after the latest support expiry.

Join and departure thresholds count canonical distinct confirmations only inside a bounded confirmation window; identical replay cannot advance either threshold. Pending departure retains the last public Online/Quiet state. Control domains use event-time ordering, so stale unblock, recovery, or contradiction-clear messages cannot reverse newer state.

Every transition includes the triggering source, evidence kind, observation/validity timestamps, arrival time, and a deterministic transition ID, and converts losslessly to the public `PresenceChanged` event. Event-bus consumers use the bounded `domain_events_since` cursor API so correction events remain independently consumable. Late traffic corrects a recent departure to Online only when it supported the departure instant; a lease, association, or eligible probe corrects it to Quiet only when its validity spanned departure. A historical correction does not claim current presence: stale evidence leaves current state Offline, while evidence still valid at arrival participates in current hysteresis separately. Older evidence cannot rewrite history outside the correction window.
